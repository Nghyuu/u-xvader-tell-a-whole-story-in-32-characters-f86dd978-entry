One Wi-Fi network name of at most 32 characters that hints at a whole story: a breakup, a dog, and one small, petty victory kept for the router.

Run `main.ts` with Node 22 and `MAKEFUN_OUTPUT_DIR` set; it writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
